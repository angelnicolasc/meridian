# Rust API

The Rust API is generated by rustdoc. Build locally with:

```bash
cargo doc --workspace --no-deps --open
```

Published documentation: <https://docs.rs/meridian-core>.

## Top-level surface

- [`meridian_core::PhaseRouter`](https://docs.rs/meridian-core/latest/meridian_core/phase_router/struct.PhaseRouter.html)
  — per-request token-stream state machine.
- [`meridian_core::MeridianScheduler`](https://docs.rs/meridian-core/latest/meridian_core/scheduler/struct.MeridianScheduler.html)
  — dual-queue scheduler.
- [`meridian_core::BlockManager`](https://docs.rs/meridian-core/latest/meridian_core/block_manager/trait.BlockManager.html)
  — trait describing the three-tier KV block manager.
- [`meridian_core::types`](https://docs.rs/meridian-core/latest/meridian_core/types/index.html)
  — `ThinkPhase`, `PhaseEvent`, `BlockTier`, `EntropySignal`.

## Stability

Pre-1.0. Public API breakage is recorded under `BREAKING CHANGE` in
[`CHANGELOG.md`](https://github.com/angelnicolasc/meridian/blob/main/CHANGELOG.md).
